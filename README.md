# EVAL-L4 — AI Output Evaluation Model

EVAL-L4 is a lightweight evaluation protocol for assessing AI outputs consistently, without drift, debate, or over-interpretation.

Most AI evaluation problems are not model failures — they are judgement failures.

EVAL-L4 addresses this by providing a simple, repeatable structure that:
- checks whether a task is valid before evaluation begins
- separates correctness from instruction-following
- classifies failures instead of arguing about them
- produces short, actionable feedback

---

## What This Is
- A portable evaluation protocol
- A human- and AI-usable rubric
- A way to turn subjective judgement into repeatable signal

## What This Is Not
- Not a benchmark
- Not a certification
- Not a governance framework
- Not a model optimisation tool

---

EVAL-L4 is available as a standalone evaluation pack.  
Consulting and calibration are available separately.
